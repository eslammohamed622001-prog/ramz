# 🌟 رَمْز (Ramz)

منظومة تطوير ويب عربية أصيلة، مصممة من الصفر لبناء المواقع والتطبيقات باستخدام لغات من تصميمنا، بدلاً من الاعتماد على HTML/CSS/JS مباشرة.

> "اكتب البرمجيات بالعربية، باستخدام لغة صُممت من البداية لهذا الغرض."

## 🏗️ مكونات المنظومة

تعتمد رَمْز على ثلاث لغات متكاملة تعمل معاً:

1. **شَكْل (Shakl)**: لغة بناء الهياكل والواجهات (بديل HTML).
2. **طِراز (Tiraz)**: لغة التنسيق والتصميم البصري (بديل CSS).
3. **مَعنى (Ma'na)**: لغة البرمجة والمنطق والتفاعل (بديل JavaScript).

## 🚀 مثال حي

إليك كيف يبدو كود صفحة ويب كاملة بلغة رَمْز:

```ramz
شكل {
    صفحة "تجربة" {
        عنوان "أهلاً بك في رَمْز"
        زر "ابدأ"
    }
}

طراز {
    تنسيق "عنوان" {
        خاصية "اللون" = "#D4AF37"
        خاصية "المحاذاة" = "وسط"
    }
}

معنى {
    عند النقر على "ابدأ" {
        أظهر "مرحباً بك في عالم رَمْز! 🎉"
    }
}
